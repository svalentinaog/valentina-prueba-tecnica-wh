# Disney 🏰

Proyecto Fullstack para gestión de personajes 🧜‍♀️.

## Stack Tecnológico

**Frontend:**

- Vite + React + TypeScript
- TanStack Query
- React Hook Form + Zod
- Tailwind CSS
- Lucide React para icons

**Backend:**

- Node.js + Express
- PostgreSQL
- Jest

## Requisitos

1. Node.js (v18 o superior).
2. PostgreSQL.

## Configuración Base de Datos

El proyecto requiere una base de datos local nombrada como:

```sql
disney_db

```

## Instalación y Ejecución

**1. Backend**

```bash
cd backend
npm install
npm run dev

```

**2. Frontend**

```bash
cd frontend
npm install
npm run dev

```

Acceder en: `http://localhost:5173`
